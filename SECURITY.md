# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through [GitHub security advisories](https://github.com/RonFBurgundy/trackseerr/security/advisories/new). Include the version or commit, the steps to reproduce, and what an attacker could do.

We aim to reply within 48 hours and to fix confirmed issues before anything else.

## Supported versions

TrackSeerr has no tagged releases yet. Fixes go to `main` and the `latest` image.

## How TrackSeerr is protected

See [Architecture and security](docs/ARCHITECTURE_AND_SECURITY.md). If TrackSeerr is reachable from the internet, use the [two-container setup](docs/INSTALL.md#two-containers).
